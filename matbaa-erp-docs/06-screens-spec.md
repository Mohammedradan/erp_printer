# 06 — مواصفات الشاشات (لكل وحدة)

> التصميم: عربي RTL، ثيم أخضر داكن مثل الإكسل الحالي + أزرق للجداول. الديسكتوب: جداول واسعة + فلاتر. الأندرويد: بطاقات + بحث + زر + عائم.

## شاشات مشتركة
- **تسجيل الدخول:** اسم المستخدم + كلمة المرور + عنوان السيرفر + "اختبار الاتصال".
- **الرئيسية (لوحة المؤشرات):** كروت (العروض المفتوحة، الأوامر قيد الإنتاج، قيمة المخزون، الذمم، ربح الشهر) + تنبيهات (تحت حد الطلب، أوامر متأخرة) + بحث سريع.
- **كل شاشة قائمة:** بحث + فلترة + ترتيب + تصدير Excel/PDF + صلاحيات (عرض/إضافة/تعديل/حذف).

## 1. قاعدة الورق
- جدول بالأعمدة التسعة + عمود "الحالة" (متوفر/تحت الحد/نافد بالألوان).
- زر "حركة دخول" سريعة من نفس الشاشة.
- التحقق: منع تكرار (الفئة/النوع/الجرام)، السعر والحد ≥ 0.

## 2. الماكينات
- بطاقة لكل ماكينة: الاسم + النوع + الهالك% + التكلفة/ساعة + السرعة + الحالة + إجمالي ساعات الشهر.
- لا حذف مع وجود ارتباط — زر "إيقاف" بدلاً من حذف.

## 3. المنتجات (قوالب)
- قائمة القوالب الأربعة الحالية + زر "منتج جديد".
- نموذج: نفس أعمدة الإكسل + صورة اختيارية + "استخدام كافتراضي".
- زر "أنشئ عرضاً من هذا القالب".

## 4. التشطيبات
- جدول (الخدمة + السعر + الوحدة) — تُعبأ الأسعار اليدوية الحالية هنا أول تشغيل.
- ملاحظة: الوحدة تُحدد بعد رفع الملف (قطعة/ألف/عملية).

## 5. محرك التسعير (أهم شاشة)
- **التصميم:** نموذج مقسم 3 كتل:
  - (أ) المدخلات: المنتج → الكمية → الصفحات/NCR → الألوان/البليتات → الخامة (3 قوائم معتمدة) → الماكينة → التشطيبات (اختيار متعدد chips) → الهامش%.
  - (ب) الحسابات الحية: الملازم/وحدة، الإجمالي، الهالك، الورق، الساعات، الماكينة، التشطيب، الزنك — تتحدث لحظياً.
  - (ج) النتائج بخط كبير: التكلفة الكلية + سعر الوحدة + قيمة البيع + الربح.
- أزرار: "حفظ في العرض" + "اعتماد" + "طباعة مسودة" + "أمر إنتاج من هذا السطر".
- تحذير نقص الرصيد يعرض: المتاح مقابل المطلوب + زر "عرض البدائل" (نفس الفئة بجرامات أخرى).

## 6. عروض الأسعار
- قائمة برقم العرض + التاريخ + العميل + المنتج + الكمية + القيمة + الحالة (ملونة).
- تفاصيل العرض: بيانات العميل + سطور التسعير + الإجماليات + الملاحظات + سجل الحالات.
- أزرار الحالة: اعتماد → توليد أمر إنتاج تلقائياً. طباعة/PDF/واتساب.

## 7. أوامر الإنتاج
- كانبان (أعمدة الحالات) في الديسكتوب + قائمة في الأندرويد.
- بطاقة الأمر: الرقم + العميل + المنتج + الكمية + الماكينة + الخامة + الأوراق (مطلوبة/مع الهالك) + الساعات + التكلفة + موعد التسليم + شريط تقدم.
- زر "صرف الورق" ينشئ حركة خروج ويربطها بالمرجع. زر "إتمام" يطلب تأكيد الكمية الفعلية.

## 8. حركات المخزون + المخزون
- تبويبان: "الأرصدة" و "الحركات".
- الأرصدة: الصنف + الرصيد فرخ + متوسط السعر + القيمة + شارة حد الطلب.
- حركة جديدة: النوع (دخول/خروج/تسوية) → الصنف → الكمية → السعر (يُقترح تلقائياً من آخر شراء/المتوسط) → المرجع → حفظ وترحيل.
- منع الكمية السالبة، وتسوية السالب تحتاج صلاحية مدير + سبب إجباري.

## 9. العملاء + المدفوعات
- ملف العميل: البيانات + 3 كروت (المبيعات/المدفوع/الرصيد) + تبويبات (العروض/الأوامر/السندات/كشف الحساب).
- سند جديد: المبلغ + الطريقة + التاريخ + المرجع + ملاحظات + طباعة سند.
- كشف حساب بفترة + رصيد متحرك + تصدير PDF.

## 10. التقارير
- تقارير جاهزة: المبيعات، الربحية (حسب عميل/منتج/فترة)، استهلاك الورق، ساعات الماكينات، الأصناف تحت الحد، أعمار الذمم.
- كل تقرير: فلاتر (من-إلى + عميل/منتج) + رسم بياني + جدول + تصدير.

## 11. الإعدادات والقوائم
- الإعدادات: نفس حقول الإكسل + بيانات المطبعة للطباعة + عنوان السيرفر + النسخ الاحتياطي.
- القوائم: إدارة (فئات الورق، أنواع الماكينات، فئات المنتجات، التشطيبات، الحالات) بواجهة بسيطة.

## ملاحظات Flutter
- الحزم: `flutter_riverpod` للحالة، `dio` للشبكة، `drift` للكاش، `pdf/printing` للطباعة، `excel` للتصدير، `fl_chart` للرسوم.
- الخط: Cairo أو Tajawal لدعم العربية.
- الديسكتوب: نوافذ قابلة للتوسيع + اختصارات (F2 حفظ، Ctrl+P طباعة، Ctrl+F بحث).
