## 3. ملخص سريع للنظام الحالي (من الصور)

الوحدات الموجودة في شيت `الرئيسية_ERP`:

| الوحدة | الوصف من الصورة |
|--------|-----------------|
| لوحة المؤشرات | لوحة مؤشرات تفاعلية |
| عروض_الأسعار | أرشيف عروض الأسعار وربطها بمحرك التسعير |
| أوامر_الإنتاج | أوامر الإنتاج والمتابعة |
| محرك_التسعير | التسعير التلقائي والمواد والهالك والماكينات |
| قاعدة_الورق | قاعدة أسعار ومخزون الورق |
| مخزون | الرصيد الحالي وقيمة المخزون |
| حركات_المخزون | حركات الدخول والخروج والتسوية |
| الماكينات | الماكينات والهالك والتكلفة/ساعة |
| المنتجات | قوالب المنتجات |
| التشطيبات | أسعار خدمات التشطيب |
| العملاء | بيانات العملاء والذمم |
| المدفوعات | سجل المدفوعات |
| تقارير_الربحية | تحليل المبيعات والتكلفة والربح |
| الإعدادات | إعدادات النظام |

شيتات ظاهرة في الصور: `الرئيسية_ERP` + `قاعدة_الورق` + `الماكينات` + `المنتجات` + `محرك_التسعير` + `التشطيبات` + `الإعدادات` + `القوائم` + `العملاء` + `عروض_الأسعار` + `أوامر_الإنتاج` + `حركات_المخزون`.
شيتات مذكورة لكن **غير مصورة**: `مخزون` + `المدفوعات` + `تقارير_الربحية` + لوحة المؤشرات. سيتم توثيقها بعد رفع الملف.

## 4. دورة العمل الأساسية

```
عميل جديد → عرض سعر (من محرك التسعير) → اعتماد العرض
→ أمر إنتاج → خصم ورق من المخزون (حركة خروج)
→ إتمام الإنتاج → تسليم → دفعة/مدفوعات → تحديث ذمة العميل
→ تقارير الربحية
```

## 5. ماذا ينقصنا لاكتمال التوثيق 100%؟

1. **رفع ملف الإكسل الأصلي** — لاستخراج:
   - المعادلات الفعلية في `محرك_التسعير` (كانت تظهر `#N/A` في الصور لأنها طريقة عرض محمية)
   - القوائم المنسدلة ومصادرها في شيت `القوائم`
   - شيتات `مخزون` و `المدفوعات` و `تقارير_الربحية` غير المصورة
2. تأكيد العملة والضريبة: الحالية `ريال يمني` + ضريبة `0%`.
3. تأكيد هل الطباعة والفواتير بالعربي فقط؟ (المفترض نعم + RTL).

**ارفع الملف هنا في المحادثة وسأحدّث الملفات `04` و `05` بالمعادلات الحرفية.**
