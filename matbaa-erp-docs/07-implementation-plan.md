# 07 — خطة التنفيذ على مراحل

## نظرة عامة
المدة التقديرية لمبرمج واحد متفرغ: **8–12 أسبوعاً**. لفريق (Flutter + Backend): **5–7 أسابيع**.

## المرحلة 0 — التثبيت والاستخراج (بعد رفع الإكسل) — 3 أيام
- [ ] استخراج كل المعادلات والقوائم والتحقق من الصحة (Data Validation).
- [ ] تحديث الملفين `04` و `05` بالصيغ الحرفية.
- [ ] إدخال البيانات الأولية: الورق + الماكينات + المنتجات + التشطيبات + الإعدادات.
- المخرج: ملف `seed-data.xlsx/csv` جاهز للاستيراد.

## المرحلة 1 — الأساس (أسبوعان)
- هيكل Flutter (موبايل+ديسكتوب) + حزمة `core` المشتركة.
- سيرفر FastAPI + قاعدة البيانات + المصادقة والصلاحيات.
- شاشات: الدخول + الإعدادات + القوائم + المستخدمون.
- إعداد LAN (IP ثابت + تشغيل تلقائي + نسخ احتياطي).
- المخرج: دخول من الجهازين + عنوان سيرفر قابل للضبط.

## المرحلة 2 — البيانات الأساسية (أسبوع)
- قاعدة الورق + الماكينات + المنتجات + التشطيبات + العملاء (CRUD كامل).
- استيراد بيانات الإكسل + تصدير.
- المخرج: كل الجداول تعمل بصلاحيات.

## المرحلة 3 — محرك التسعير + العروض (أسبوعان — الأهم)
- تنفيذ معادلات التسعير في Dart + مطابقتها مع السيرفر (اختبارات وحدة).
- شاشة التسعير الحية + سطور العرض + `price_snapshot`.
- دورة العرض: مسودة → اعتماد/رفض + طباعة PDF + مشاركة.
- اختبار قبول: 10 عروض حقيقية من دفاترك تُطابق الإكسل ± ريال واحد.
- المخرج: تسعير شغال يغني عن الإكسل.

## المرحلة 4 — الإنتاج والمخزون (أسبوعان)
- أوامر الإنتاج (كانبان + حالات + مواعيد).
- التوليد من عرض معتمد + صرف الورق التلقائي.
- الحركات (دخول/خروج/تسوية) + شاشة الأرصدة + تنبيه حد الطلب.
- المخرج: دورة (عرض → أمر → خصم مخزون) مغلقة.

## المرحلة 5 — المدفوعات والتقارير (أسبوع)
- السندات + كشف الحساب + الذمم.
- لوحة المؤشرات + 6 تقارير أساسية.
- المخرج: محاسب يقدر يشتغل يومياً.

## المرحلة 6 — التشغيل التجريبي والإطلاق (أسبوع)
- تشغيل متوازي مع الإكسل لمدة 1–2 أسبوع.
- تدريب المستخدمين + دليل استخدام مصور.
- إصلاح الفروقات + الإطلاق الرسمي + خطة نسخ احتياطي.

## معايير القبول لكل مرحلة
1. يعمل على LAN بدون إنترنت.
2. RTL عربي سليم + طباعة سليمة.
3. صلاحيات مطبقة على الواجهة والـ API.
4. لا فقدان بيانات عند انقطاع الشبكة (صندوق الصادر).

## المخاطر والتخفيف
| الخطر | التخفيف |
|-------|---------|
| معادلات الإكسل غير مكتملة | التجميد على نسخة معتمدة + اختبار بـ 10 حالات حقيقية |
| انقطاع كهرباء/شبكة | كاش محلي + UPS للسيرفر + نسخ احتياطي يومي |
| مقاومة المستخدمين | إبقاء نفس المصطلحات والأعمدة + تدريب قصير |
| تعدد المستخدمين | أرقام من السيرفر فقط + صلاحيات دقيقة |
