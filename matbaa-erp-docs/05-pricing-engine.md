# 05 — محرك التسعير (قلب النظام)

> المعادلات أدناه **مستنتجة من أسماء الأعمدة** في الصور ومنطق المطابع. الصيغ الحرفية (VLOOKUP/XLOOKUP/IF) تُستخرج من ملف الإكسل بعد رفعه وتُطابق مع هذا الملف سطراً بسطر.

## 1. المدخلات (لكل سطر تسعير)

| الحقل | المصدر |
|-------|--------|
| المنتج | قائمة المنتجات (يعبّئ الافتراضيات) |
| الكمية/الدفاتر، عدد الصفحات، نسخ NCR، أوراق/دفتر، عدد الدفاتر | إدخال يدوي |
| الألوان، البليتات | إدخال (البليتات قد تُشتق من الألوان) |
| تكلفة البليت | افتراضي من الإعدادات = 1250، قابل للتجاوز |
| هامش الربح % | افتراضي = 30%، قابل للتجاوز |
| فئة الخامة + نوع الخامة (+ الجرام) | قوائم معتمدة من قاعدة_الورق |
| الماكينة | قائمة الماكينات النشطة |
| التشطيبات (متعدد) | قائمة التشطيبات |

## 2. الثوابت من الإعدادات

`مقاس الفرخ 100x70 | مقاس الملزمة 50x35 | عدد الملائم 4 | سعر البليت 1250 | هامش الربح 30% | ساعات العمل 8 | العملة ريال يمني | الضريبة 0%`

## 3. خطوات الحساب (بالترتيب)

```
1) sheets_per_unit (الملازم/وحدة) = pages / pages_per_sheet
   - pages_per_sheet من قالب المنتج (8 للكتاب A5، 4 للمجلة A4 والدفاتر).
   - لدفاتر NCR: تُحسب بالأوراق: total_sheets = books_count × sheets_per_book × ncr_copies (يُؤكد بعد الرفع).

2) total_sheets (إجمالي الأوراق) = sheets_per_unit × qty
   - مع التقريب لأعلى (CEILING) لأن نصف الفرخ يُشترى فرخاً.

3) waste_pct (الهالك %) = من سجل الماكينة (5% أوفست / 2% ديجيتال / 1% تصوير).
   - قد يُضاف هالك تشطيب — يُؤكد بعد الرفع.

4) sheets_with_waste = total_sheets × (1 + waste_pct/100)  → (عمود "الأوراق مع الهالك").

5) paper_cost (تكلفة الورق) = sheets_with_waste × sheet_price
   - sheet_price يُجلب من papers حسب (category + type + gsm).

6) run_hours (ساعات التشغيل) = sheets_with_waste / speed_per_hour
   - السرعة من سجل الماكينة (5000/1200/800).

7) machine_cost (تكلفة الماكينة) = run_hours × hourly_cost.

8) plates_cost = plates_count × plate_cost.
   - plates_count: من الإدخال أو = عدد الألوان (يُؤكد بعد الرفع).

9) finishing_cost (تكلفة التشطيب) = Σ (سعر الخدمة × الكمية بوحدتها).
   - الوحدة (قطعة/ألف/عملية) تُحسم بعد الرفع.

10) zinc_cost (تكلفة الزنك) = ؟ — العمود موجود في الإكسل.
    - الاحتمال الأقوى أنه نفس plates_cost باسم آخر، أو تكلفة زنكات الأوفست.
    - القرار: بعد رفع الملف، إما ندمجه مع plates_cost أو نُبقيه بنداً مستقلاً.

11) line_total_cost (التكلفة الكلية) = paper_cost + machine_cost + plates_cost + finishing_cost + zinc_cost.

12) unit_price (سعر الوحدة) = line_total_cost × (1 + margin/100) / qty.

13) line_amount (قيمة البيع) = unit_price × qty.

14) profit (الربح) = line_amount − line_total_cost.
```

## 4. مثال محسوب (للتحقق لاحقاً)

كتاب A5: `qty=1000 نسخة، pages=100، pages_per_sheet=8، ورق أوفست أبيض 70 بسعر افتراضي 100 ريال/فرخ، ماكينة أوفست (هالك 5%، سرعة 5000، تكلفة ساعة 5000)، بليتات 4×1250، تشطيب تجليد حراري 5000، هامش 30%`:

```
sheets_per_unit = 100/8 = 12.5 → إجمالي = 12.5×1000 = 12500 فرخ
مع الهالك = 12500×1.05 = 13125 فرخ
تكلفة الورق = 13125×100 = 1,312,500
ساعات التشغيل = 13125/5000 = 2.625 ساعة
تكلفة الماكينة = 2.625×5000 = 13,125
البليتات = 4×1250 = 5,000
التكلفة الكلية = 1,312,500+13,125+5,000+5,000 = 1,335,625
سعر الوحدة = 1,335,625×1.3/1000 ≈ 1,736 ريال
قيمة البيع ≈ 1,736,313 ريال
```

> الأرقام للتحقق من المنطق فقط — الأسعار الحقيقية من ملفك.

## 5. قواعد يجب تثبيتها في الكود

1. التقريب لأعلى في الأوراق، والتقريب لأقرب ريال في الأسعار.
2. حفظ `price_snapshot` مع كل سطر: (سعر الفرخ المستخدم، تكلفة الساعة، أسعار التشطيبات وقتها).
3. أي تغيير في الأسعار الأساسية لا يعدّل العروض القديمة.
4. منع الحفظ إذا: الكمية ≤ 0، أو الورق غير موجود، أو الماكينة موقوفة.
5. تحذير (وليس منع) إذا الرصيد المتاح < الأوراق مع الهالك.

## 6. ما سنستخرجه من ملف الإكسل بعد الرفع (قائمة تحقق)

- [ ] صيغة `الملازم/وحدة` و `إجمالي الأوراق` لكل نوع منتج (كتب vs دفاتر NCR).
- [ ] صيغة `الهالك %` (من الماكينة فقط أم + إضافي؟).
- [ ] صيغة `تكلفة الورق` (أي عمود سعر؟ وهل فيه VLOOKUP بالجرام؟).
- [ ] صيغة `ساعات التشغيل` و `تكلفة الماكينة`.
- [ ] صيغة `تكلفة التشطيب` ووحدة كل خدمة.
- [ ] معنى عمود `تكلفة الزنك` وعلاقته بالبليتات.
- [ ] صيغة `البليتات` (يدوي أم من الألوان؟).
- [ ] صيغة `سعر الوحدة` و `قيمة البيع` (شامل/بدون ضريبة؟).
