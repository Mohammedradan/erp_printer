# 02 — المتطلبات الوظيفية وغير الوظيفية

## 1. الهدف
نظام مطبعة يعمل على **أندرويد + ويندوز** بنفس منطق الإكسل الحالي، مع قاعدة بيانات موحدة على شبكة محلية.

## 2. المستخدمون والأدوار المقترحة

| الدور | الصلاحيات |
|-------|-----------|
| مدير | كل شيء + الإعدادات + التقارير + اعتماد العروض |
| مبيعات | العملاء + عروض الأسعار + محرك التسعير (بدون تعديل الأسعار الأساسية) |
| إنتاج | أوامر الإنتاج + حالاتها + استهلاك الورق |
| مخازن | قاعدة الورق + حركات المخزون + التسويات + تنبيه حد إعادة الطلب |
| محاسب | المدفوعات + ذمم العملاء + تقارير الربحية |

- تسجيل دخول باسم مستخدم + كلمة مرور، والصلاحيات على مستوى الشاشة والزر (عرض/إضافة/تعديل/حذف/اعتماد).

## 3. المتطلبات الوظيفية (حسب الوحدة)

### 3.1 قاعدة الورق
- CRUD للأصناف: الفئة + النوع + الجرام + مقاس الفرخ + عدد الملائم + سعر الفرخ + حد إعادة الطلب + المورد.
- منع التكرار لنفس (الفئة/النوع/الجرام).
- تنبيه عند وصول الرصيد ≤ حد إعادة الطلب.
- بحث وفلترة حسب الفئة والنوع والجرام.

### 3.2 الماكينات
- CRUD: الاسم + النوع (Offset/Digital/Copier/أخرى) + الهالك% + تكلفة التشغيل/ساعة + السرعة فرخ/ساعة + الحالة (نشطة/موقوفة).
- لا يمكن حذف ماكينة مرتبطة بعروض/أوامر (أرشفة بدلاً من الحذف).

### 3.3 المنتجات (قوالب)
- CRUD للقوالب مع الحقول الحالية + صورة اختيارية.
- اختيار قالب يعبّئ افتراضيات محرك التسعير.

### 3.4 التشطيبات
- CRUD للخدمات + السعر + **وحدة السعر** (للقطعة / للألف / للعملية — تُحسم في التصميم).
- إمكانية اختيار أكثر من تشطيب في العرض الواحد.

### 3.5 محرك التسعير
- إدخال سطر تسعير مرتبط برقم عرض.
- قوائم منسدلة معتمدة (الفئة → النوع → الجرام).
- حساب تلقائي فوري لكل تغيير (انظر ملف 05).
- استخدام الإعدادات الافتراضية (سعر البليت 1250، هامش 30%) مع إمكانية التجاوز لكل سطر.
- حفظ نسخة من الأسعار المستخدمة وقت التسعير (حتى لو تغيرت الأسعار لاحقاً يبقى العرض ثابتاً).

### 3.6 عروض الأسعار
- إنشاء/تعديل/اعتماد/رفض/إلغاء العرض.
- ترقيم تلقائي (مثال: Q-2026-0001).
- طباعة / PDF / مشاركة واتساب.
- الحالات: مسودة → معتمد → (تحوّل لأمر إنتاج) / مرفوض / ملغي.
- الربح = قيمة العرض − التكلفة الكلية.

### 3.7 أوامر الإنتاج
- توليد أمر من عرض معتمد بنقرة واحدة (نسخ كل بيانات التسعير).
- الحالات: مسودة → معتمد → قيد الإنتاج → مكتمل / ملغي.
- موعد التسليم + تنبيه للتأخير.
- عند بدء الإنتاج: إنشاء حركة خروج مخزون تلقائياً (قابلة للمراجعة).

### 3.8 المخزون والحركات
- حركات: دخول (شراء) / خروج (إنتاج) / تسوية (جرد/تالف).
- رقم حركة تلقائي + منع التعديل بعد الترحيل إلا بصلاحية + سجل تدقيق.
- شاشة الرصيد الحالي: الصنف + الرصيد بالفرخ + متوسط سعر الشراء + القيمة الإجمالية.
- تقرير حركة صنف خلال فترة.

### 3.9 العملاء والمدفوعات
- ملف عميل: كود تلقائي + الاسم + الهاتف + العنوان + الرصيد الافتتاحي.
- كشف حساب عميل (المبيعات + المدفوعات + الرصيد).
- سندات قبض/دفع مع طريقة الدفع (نقدي/تحويل/آجل).

### 3.10 التقارير ولوحة المؤشرات
- لوحة: عدد العروض المفتوحة، الأوامر قيد الإنتاج، قيمة المخزون، إجمالي الذمم، ربح الشهر.
- تقارير: المبيعات حسب (الفترة/العميل/المنتج)، الربحية، استهلاك الورق، ساعات الماكينات، الأصناف تحت حد الطلب.

### 3.11 الإعدادات والقوائم
- نفس إعدادات الإكسل + إعدادات الطباعة (ترويسة المطبعة، الشعار، التذييل).
- إدارة القوائم (فئات الورق، الحالات، الوحدات) بدون برمجة.

## 4. المتطلبات غير الوظيفية
- **اللغة:** عربي كامل + RTL، الأرقام عربية أو لاتينية حسب الإعداد.
- **العملة:** ريال يمني، بدون ضريبة حالياً (0%) مع دعم تفعيلها لاحقاً.
- **الأداء:** فتح أي شاشة < 2 ثانية على الشبكة المحلية، وحساب التسعير لحظي.
- **الموثوقية:** نسخ احتياطي يومي تلقائي لقاعدة البيانات + تصدير Excel.
- **الأمان:** كلمات مرور مشفرة، جلسات، سجل تدقيق (من عدّل ماذا ومتى).
- **العمل دون إنترنت:** يعمل كاملاً على LAN بدون إنترنت؛ نسخة الأندرويد تخزّن مؤقتاً وتزامن عند الاتصال بالسيرفر.
- **الطباعة:** دعم طابعات A4/F5 للعروض والأوامر والسندات + ملصقات.

## 5. خارج النطاق (حالياً)
- المحاسبة الكاملة (قيود، ميزانية) — نكتفي بالذمم والمدفوعات.
- إدارة الموردين والمشتريات الكاملة — حقل مورد نصي أولاً.
- الفروع المتعددة عبر الإنترنت — مرحلة لاحقة بعد استقرار LAN.
